## 🧩 About

**The Forest Map** is a curated list of The Forest open-source tools:

- **Mod Menus** — map overlay, item spawner, god mode, teleport, no clip
- **UI Automation Bots** — resource gathering bot, auto-build, input helpers for single-player study
- **Quality-of-Life Mods** — map markers, inventory manager, overlay helpers
- **Research Frameworks** — map seed explorers and config notes for educational use

Based on publicly available community tools like **The Forest Trainer**, **Forest Mod Menu**, and **QoL Mods**.
